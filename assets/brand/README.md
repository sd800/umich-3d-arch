# Campus project icon

Independent project icon: a maize block M above a plain rectangular map with a route and location pin, on Michigan blue.
Signature color references: Michigan Blue `#00274c`, Michigan Maize `#ffcb05`, from the [2025 U-M brand guide](https://brand.umich.edu/wp-content/uploads/2025/02/250027-U-M-Style-Guide-February2025.pdf).

The editable source is `m-map.svg`; PNG and favicon sizes accompany it. This project is independent and the icon does not indicate university endorsement.

M geometry proportions reference: [Block M on the university home page](https://umich.edu/includes/panels/gallery/images/block-m-maize.png). Both axes are scaled uniformly. Run `python3 scripts/build_brand.py` to rebuild SVG, PNG and favicon sizes.
